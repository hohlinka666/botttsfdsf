# Vuitton bot

## Интерфейс бота (v2)
Меню внизу подстраивается под человека:
- **Гость** (ещё не в команде): 🎧 Оператор · 🔎 Скаут · 📸 Модель · 📋 Мои заявки · ℹ️ О проекте · ❓ Помощь.
- **Участник команды**: 📝 Отчёт · 👤 Профиль · 👥 Команда · 🏆 Рейтинг · 📱 Кабинет · ❓ Помощь.
- **Админ**: сверху добавляется 🛠 Админ-панель; в приветствии видно, сколько всего ждёт решения.

Что изменилось:
- **Отчёт** — один экран, который обновляется на месте: часы и числа выбираются кнопками (или вводятся вручную),
  есть «⬅️ Назад», итоговая сводка с «✅ Отправить на проверку». Если отчёт за сегодня уже есть — бот предупреждает.
- **Профиль**: статус отчёта за сегодня, «📋 Мои отчёты» (с причинами отклонения), короткая статистика.
- **👥 Команда**: состав, ссылка для вступления, кто из команды не сдал отчёт сегодня; «➕ Добавить работника».
- **Заявки**: «📋 Мои заявки» показывает статусы и позволяет подать недостающие; в вопросах есть кнопка отмены;
  кнопки меню больше не принимаются за ответ на вопрос.
- **Админ-панель**: очереди с цифрами сверху (отчёты, заявки, запросы команд), остальное сгруппировано;
  «📣 В группу…» объединяет отправку в группы.
- Меню обновляется само при смене ранга, одобрении заявки и вступлении в команду.
Mini App (`webapp.py`, `webapp/index.html`) не менялся: его кнопка «добавить работника» по-прежнему добавляет сразу по @username, без анкеты и согласия.

## Запуск
    python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
    pip install -r requirements.txt
    cp .env.example .env      # заполнить BOT_TOKEN и ADMIN_IDS
    python bot_fixed.py

## Важно
- Бот должен быть администратором канала CHANNEL_USERNAME, иначе проверка подписки отключится (в логе предупреждение).
- Админ-панель: /opcaadmin (алиас /opcaadm). Работает только для ADMIN_IDS.
- Чтобы работали напоминания в чатах, добавьте бота в группу от имени админа.
- База (SQLite) создаётся и мигрируется автоматически. Старые отчёты после обновления считаются подтверждёнными.

## Проверка отчётов
Каждый новый отчёт приходит всем админам с кнопками «Подтвердить», «Отклонить» (с причиной), «Написать через бота» и «Открыть чат».
Отклонённые отчёты не учитываются в статистике и рейтинге, автор получает уведомление и может сдать отчёт заново.
Очередь: /opcaadmin → «🧾 Отчёты на проверку».

## «У @user новая модель»
/opcaadmin → «🎉 Разослать модель»: указываете @username (+ комментарий), смотрите предпросмотр и выбираете:
в группу и в бота / только в группу / только в бота. В боте получают участники команд, лидеры и сам скаут.
Группа: ALERT_GROUP_ID, если пусто — SCOUT_GROUP_ID, затем MODEL_GROUP_ID. Бот должен быть в группе.
Кнопка «🎉 Разослать модель» также появляется в карточке отчёта, где указаны модели.

## Люди и команды
**Анкета** (одна и та же для заявки и для работника): 1) фамилия и имя · 2) дата рождения · 3) телефон · 4) Telegram · 5) уровень английского · 6) опыт · 7) наушники (есть/нет) · 8) страна.

**Возраст**: скаутом можно работать с любого возраста (от 10 лет, без «нужно 18»); оператором и моделью — с 18 лет.
Если оператору меньше 18, бот предлагает подать заявку скаутом с уже введёнными данными.

**🆕 Привести работника** (скауты, тимлиды; админ — в любую команду; `/addworker`). Команда не нужна:
выбираете роль (скаут / оператор / модель), заполняете анкету, бот запоминает @username и выдаёт личную одноразовую ссылку.
Когда человек запустит бота (или откроет ссылку), он сразу оформляется в нужную роль и попадает в команду приводящего
(скаут — в команду, где состоит; если команды нет — остаётся без команды). Анкета видна админу в карточке пользователя.

**➕ Добавить в команду** (`/addmember`): для тех, кто уже работает в боте. Вводите @username → человеку приходит приглашение
«Подтвердить / Отказаться». Если он уже в другой команде, после «Подтвердить» бот спрашивает «Точно выйти из «X» и перейти в «Y»? Да / Нет».
Лидерам обеих команд и приглашающему приходят уведомления. Приглашение действует 7 дней. Тимлидов приглашать нельзя (переводит админ).

**🙋 Запрос команды** — только для младшего тимлида (кто зарабатывает на своих скаутах). Скауты работают в команде лидера.
Заявка → всем админам с кнопками «Создать команду», «Отклонить», «Другое название и создать».

## Кабинет (Mini App): что изменилось
Вкладки: Главная · Отчёт · Команда · Рейтинг · Админ (Отчёты / Команды / Модель). Формы открываются в нижней шторке,
счётчики в отчёте — с кнопками +/−, ошибки подсвечиваются у поля. Исправлено: белый экран «Загрузка…» при обрыве сети
(теперь экран с кнопкой «Повторить»), гонка при быстром переключении вкладок, нерабочая кнопка «Связаться» у людей без @username,
отчёт с пустым полем часов уходил как 0, рейтинг был открыт пользователям без команды.
Названия команд теперь сравниваются без учёта регистра и для кириллицы (раньше «Волки» и «волки» считались разными).

## Mini App («Кабинет»)
Профиль и статистика, сдача отчёта со статусами, рейтинг; у админов — проверка отчётов и оповещение о модели.
1. Запустите бота — он сам поднимет веб-сервер на WEBAPP_PORT (по умолчанию 8080).
2. Нужен публичный HTTPS-адрес на этот порт. Самый быстрый вариант для теста:
       cloudflared tunnel --url http://localhost:8080
   (или `ngrok http 8080`). На сервере — nginx/Caddy с сертификатом.
3. Впишите адрес в .env: WEBAPP_URL=https://xxxx.trycloudflare.com и перезапустите бота.
4. В боте появятся кнопка меню «Кабинет», команда /app и кнопка «📱 Кабинет».
Подлинность пользователя проверяется по подписи Telegram (initData), без неё API не отвечает.

## Доработки профилей и модерации

В этой версии добавлены:
- редактирование собственной анкеты в Mini App с повторной отправкой на проверку;
- список приглашённых пользователей с отображением статуса анкеты;
- обязательная модерация новых анкет: роль и добавление в команду активируются только после одобрения администрацией;
- заявки на смену роли с решением администратора;
- проверка повторов телефона и Telegram username при сохранении анкеты;
- административный поиск по фамилии, имени, username и телефону (без фильтров по стране, уровню английского и ФИО целиком).

Для применения изменений остановите бота и запустите его обновлённую версию. Новые таблицы и поля создаются автоматически через `init_team_db()`. Старые анкеты при миграции сохраняют статус `approved`, чтобы не сбрасывать ранее подтверждённые данные. Новые анкеты получают статус `pending`.
