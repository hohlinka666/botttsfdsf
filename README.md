# Vuitton bot

## Запуск
    python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
    pip install -r requirements.txt
    cp .env.example .env      # заполнить BOT_TOKEN и ADMIN_IDS
    python bot_fixed.py

## Важно
- Бот должен быть администратором канала CHANNEL_USERNAME, иначе проверка подписки отключится (в логе предупреждение).
- Админ-панель: /opcaadmin (алиас /opcaadm). Работает только для ADMIN_IDS.
- Чтобы работали напоминания в чатах, добавьте бота в группу от имени админа.
- База (SQLite) создаётся и мигрируется автоматически. Старые отчёты после обновления считаются подтверждёнными.

## Проверка отчётов
Каждый новый отчёт приходит всем админам с кнопками «Подтвердить», «Отклонить» (с причиной), «Написать через бота» и «Открыть чат».
Отклонённые отчёты не учитываются в статистике и рейтинге, автор получает уведомление и может сдать отчёт заново.
Очередь: /opcaadmin → «🧾 Отчёты на проверку».

## «У @user новая модель»
/opcaadmin → «🎉 Разослать модель»: указываете @username (+ комментарий), смотрите предпросмотр и выбираете:
в группу и в бота / только в группу / только в бота. В боте получают участники команд, лидеры и сам скаут.
Группа: ALERT_GROUP_ID, если пусто — SCOUT_GROUP_ID, затем MODEL_GROUP_ID. Бот должен быть в группе.
Кнопка «🎉 Разослать модель» также появляется в карточке отчёта, где указаны модели.

## Добавить работника и запрос команды
**➕ Добавить работника** (скауты, тимлиды; админ — в любую команду). Профиль → «➕ Добавить работника», команда `/addworker`
или вкладка «Команда» в Кабинете. Выбираете роль (скаут / оператор / модель) и вводите @username или ID.
- Человек уже запускал бота и не состоит в команде — сразу попадает в вашу команду (если ранга нет, ставится выбранная роль),
  ему и лидеру приходит уведомление.
- Человека ещё нет в базе — сохраняется приглашение: он попадёт в команду сам, как только запустит бота с этим @username,
  либо по личной одноразовой ссылке (её можно скопировать или отправить из Кабинета). Лимит — 30 неиспользованных приглашений на человека.
- Нельзя: добавить себя, админа, тимлида, заблокированного, или человека из другой команды (перевод — через наставника/админа).
Скаут без команды сначала запрашивает её (см. ниже). Скаут-участник добавляет людей в команду, где состоит.

**🙋 Запросить команду** (скауты и тимлиды): Профиль → «🙋 Запросить команду», `/requestteam` или Кабинет. Название + комментарий →
всем админам приходит заявка с кнопками «✅ Создать команду», «❌ Отклонить», «✏️ Другое название и создать»
(также /opcaadmin → «🙋 Запросы команд» и вкладка «Админ → Команды» в Кабинете). При одобрении команда создаётся,
заявитель становится лидером (скауту выдаётся «Младший тимлид 1 ур.») и получает реферальную ссылку. Одна активная заявка на человека.

## Кабинет (Mini App): что изменилось
Вкладки: Главная · Отчёт · Команда · Рейтинг · Админ (Отчёты / Команды / Модель). Формы открываются в нижней шторке,
счётчики в отчёте — с кнопками +/−, ошибки подсвечиваются у поля. Исправлено: белый экран «Загрузка…» при обрыве сети
(теперь экран с кнопкой «Повторить»), гонка при быстром переключении вкладок, нерабочая кнопка «Связаться» у людей без @username,
отчёт с пустым полем часов уходил как 0, рейтинг был открыт пользователям без команды.
Названия команд теперь сравниваются без учёта регистра и для кириллицы (раньше «Волки» и «волки» считались разными).

## Mini App («Кабинет»)
Профиль и статистика, сдача отчёта со статусами, рейтинг; у админов — проверка отчётов и оповещение о модели.
1. Запустите бота — он сам поднимет веб-сервер на WEBAPP_PORT (по умолчанию 8080).
2. Нужен публичный HTTPS-адрес на этот порт. Самый быстрый вариант для теста:
       cloudflared tunnel --url http://localhost:8080
   (или `ngrok http 8080`). На сервере — nginx/Caddy с сертификатом.
3. Впишите адрес в .env: WEBAPP_URL=https://xxxx.trycloudflare.com и перезапустите бота.
4. В боте появятся кнопка меню «Кабинет», команда /app и кнопка «📱 Кабинет».
Подлинность пользователя проверяется по подписи Telegram (initData), без неё API не отвечает.
